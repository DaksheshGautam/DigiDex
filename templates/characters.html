01 / Write something

For better accuracy, choose Digits, Uppercase, Lowercase or Symbols when your drawing uses just that group. Mixed mode has more ambiguity.
Write one line, up to 32 characters. Leave a clear gap between each character. Keep the normal strokes of each character together, including dots. Use plain print rather than cursive or joined-up writing.

03 / Help improve the reading

Private online dataset

Connect once, then correcting a character saves its drawing and label automatically. Only your explicit corrections are collected. Predictions alone are never treated as correct answers. Retraining happens separately in Colab.

Use the same writer ID on your devices. Give each different person their own ID. Check that a character's box contains only that character; use the full-line correction field when the boxes are wrong.
